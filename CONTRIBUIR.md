# Contribuir

Este repositorio acompaña un manuscrito científico en preparación. Los cambios deben conservar la trazabilidad entre fuente, cálculo, tabla y afirmación.

1. No modifique directamente documentos externos ni versiones originales.
2. Registre toda corrección de datos en una nueva versión procesada y explique el motivo.
3. No sustituya un valor faltante por cero.
4. Distinga valores reportados, derivados, interpolados, conservadoramente trasladados y provisionales.
5. Ejecute `python3 analisis/scripts/verificar_indicadores.py` antes de proponer cambios.
6. No describa IC_REP_est como cumplimiento oficial, eC como sustitución observada ni IRP como emisiones evitadas realizadas.
7. No publique un MCI numérico mientras falten entradas compatibles para W, Wf, Wc y F(X).
